# Деньги Сони — автономная версия

Приложение целиком работает в браузере: без сервера, без терминала, без интернета
(после первого открытия). Данные хранятся только на устройстве; перенос между
Mac и iPhone — через файл-копию в iCloud Drive (страница «Загрузка»).

Файлы:
- index.html, style.css, app.js — интерфейс
- engine.js — чтение выписок (PDF/CSV) и категории
- store.js — хранилище в браузере (IndexedDB), резервная копия и слияние
- sw.js — офлайн-режим
- vendor/ — Chart.js и pdf.js, fonts/ — шрифты Cormorant и Onest

Чтобы открыть на iPhone и Mac, папку нужно выложить на любой статический хостинг
с https (например, GitHub Pages). Локально: `python3 -m http.server` в этой папке
и открыть http://localhost:8000.
